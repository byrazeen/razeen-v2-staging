# RAZEEN V2 STAGING

**This repository is RAZEEN V2 STAGING and must never connect to RAZEEN Production resources.**

هذه بيئة تطوير معزولة لإعادة بناء تجربة رزين. **لا تحمل بيانات عملاء، ولا تتصل بقاعدة الإنتاج، ولا ترسل رسائل، ولا تحصّل أموالاً.**

## العزل

يمتنع التطبيق عن الإقلاع إن اكتشف أي أثر للإنتاج:

- مرجع Supabase الإنتاج · نطاق `byrazeen.com` · مضيفات الدفع والرسائل الحقيقية · معرّفات القياس الحقيقية
- أو إن كانت متغيرات staging ناقصة، أو أي محوّل خارجي في وضع `live`

الحارس في `src/config/envGuard.ts`، وتوقيعات الإنتاج في `src/config/productionSignatures.ts`.

```bash
node tests/guard.negative.mjs   # 22 اختباراً سلبياً
node tests/mutation-proof.mjs   # يُثبت أن الاختبار يفشل إذا عُطِّل الحارس
```

## الخدمات الخارجية

لا تتصل الواجهة بأي مزوّد مباشرة. كل شيء خلف `src/adapters/` — دفع، رسائل، بريد، شحن، قياس — وكلها في staging **mock**. ما كان سيُرسَل يُسجَّل في `outbox` بدل تنفيذه.

## الرحلات والشاشات

- `/search` — يعرف اسم العطر: بحث عربي مطبَّع (أ إ آ → ا · ة → ه · ى → ي · بلا تشكيل) ومطابقة جزئية.
- `/custom` — عطر مخصص: اقتراحات حيّة، ومسار «لم أجد عطري»، وحجم، وسعر تجريبي.
- `/discover` — ثلاثة أسئلة وترشيحات **مع سبب كل ترشيح**.
- `/cart` · `/checkout` — سلة مختلطة (جاهز + مخصص)، تحقّق من النموذج، ودفع وهمي **بنتيجة تُختار** (نجاح/فشل) كي يُختبر المساران.
- `/admin` — لوحة تجريبية خلف **دخول وهمي** (الرمز `staging`، وليست مصادقة): الطلبات، وتحديث حالتي التصنيع والشحن، وتصدير CSV بـUTF-8 BOM.
- `/admin/queue` — قائمة التصنيع: **المدفوع فقط**. القاعدة في `repository.listProductionQueue` و`isProductionEligible`.
- `/outbox` — كل رسالة *كانت* ستُرسَل: القناة والمستلم والنص والوقت. لم تُرسَل واحدة.

حالة الخطأ قابلة للتشغيل على أي صفحة بإضافة `?stgFail=1`.

## التسعير

كل رقم في التطبيق من `src/lib/pricing.ts` — سياسة التسعير المعتمدة، ومصدر واحد لا تحسب أي صفحة رقماً خارجه. الحساب كله بالفلس الصحيح (100 فلس = 1 درهم).

- **العطر الجاهز**: السعر المخزَّن للمقاس (`product_variants.price_fils`) كما هو — بلا معادلة وبلا مضاعِف مقاس.
- **بلا سعر صالح** (غائب أو `price_fils <= 0`): «غير متاح حالياً»، والإضافة للسلة معطَّلة، ولا يُخترع سعر.
- **العطر المخصص**: 50ml = 280 درهم، 100ml = 320 درهم. لا مقاس آخر.
- **الشحن**: 25 درهماً ثابتة.
- **من 3 عطور فأكثر** (جاهز ومخصص معاً): شحن مجاني **و**خصم 5% على مجموع العطور، بتقريب النصف لأعلى على الفلس، معرَّف مرة واحدة في `roundHalfUpFils`.

`npm run test:pricing` يثبت الحدود، ويثبت أن ما يُخزَّن في الطلب مطابق حرفياً لما عُرض للعميل.
