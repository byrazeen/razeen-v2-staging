## ما اكتمل عند هذه النقطة

**العزل.** حارس يمنع الإقلاع عند أي تكوين إنتاجي، ويفشل **مغلقاً**: غياب الإعداد نفسه حالة غير آمنة، والافتراضيات محصورة في خادم التطوير فلا تُبطل الفحص في نشرة. كل المحوّلات الخارجية وهمية أو معطّلة، وصفر طلب لطرف ثالث.

**قاعدة البيانات.** عشر هجرات مطبَّقة. 16 جدولاً، RLS على 16/16، وسياسات مقيِّدة تمنع كل كتابة عميل على `payment_status` و`status` و`payments` و`inventory_movements` و`production_queue` و`shipments` و`audit_logs` — بطبقتين: صلاحيات الأعمدة وسياسات `AS RESTRICTIVE`.

**هوية الضيف.** في مخططنا لا في خدمة مصادقة: الرمز الخام في المتصفح، والهاش وحده في القاعدة. تسع دوال `SECURITY DEFINER` تتحقق من الرمز قبل أي صف، بثلاثة أخطاء متمايزة. **لا إعداد لوحة تحكّم مطلوب.**

**التسعير في الخادم.** `place_order_core` هو الحساب الوحيد — يستدعيه مسار الضيف والمسار الموقَّع معاً، فلا تنحرف نسخة عن أخرى. المتصفح يرسل معرّفات وكميات، **ولا مبلغ يغادره**. عدم التكرار بمفتاح، والمدفوع وحده يدخل طابور الإنتاج.

**الواجهة.** الرحلات الثلاث، السلة المختلطة، دفع تجريبي بنتيجتيه، لوحة إدارة، طابور، شحن، CSV، صندوق صادر. هوية بصرية موروثة ومُنضَجة، وأسطح تصفّح تقودها الصورة، وتباين يجتاز AA بالقياس.

**البوابات.** أربع وظائف على GitHub Actions تفرض: TypeScript والبناء · اختبارات العزل و mutation-proof وإثبات رفض الحقن · فحص الأسرار ومراجع الإنتاج وتاريخ Git · RLS على PostgreSQL حقيقي مع إثبات طفرة.

## متطلبات الإطلاق التجاري — موثَّقة، غير منفَّذة

**لا يُنفَّذ أيٌّ منها في هذه المرحلة.** كلٌّ مذكور بسببه لا باسمه وحده، كي لا يُعاد اكتشافه لاحقاً.

### ١. اختبار متصفح End-to-End كامل

ما هو مُثبت اليوم مُثبت على مستوى SQL بأدوار حقيقية، وعلى مستوى المتصفح **بنقل معترَض**. الطبقة غير المقيسة هي رحلة HTTP الفعلية بين المتصفح وPostgREST: أشكال JSON، ورموز حالة الأخطاء الثلاثة، وأشكال التضمين في قراءة الطلب.

السبب أن بيئة التطوير تحجب `*.supabase.co` و`*.github.io` على مستوى الوكيل. الاختبار يحتاج بيئة تسمح بالخروج إليهما.

### ٢. حماية الحافة: تحديد لكل IP و Turnstile

**حدّ معلن**: عنوان IP ليس محوراً متاحاً في SQL — PostgREST لا يمرّره و`inet_client_addr()` تُرجع المجمّع. فسقف إصدار الجلسات الحالي (300/10 دقائق) يحمي القاعدة من الإغراق **ولا يمنع مهاجماً واحداً من استهلاك حصة الجميع**.

و Turnstile يتطلب تحميل `challenges.cloudflare.com`، وهو يصطدم بقيد «صفر طلب لطرف ثالث» الذي تفرضه اختبارات العزل. تفعيله قرار يُتخذ مع رفع ذلك القيد، لا قبله.

**قبل أي إطلاق عام**: تحديد معدّل لكل IP على الحافة، وTurnstile في Supabase → Attack Protection مع تمرير `captchaToken` عند إصدار جلسة الضيف.

### ٣. تقوية حفظ Guest Token

الرمز اليوم في `localStorage`. يكفي لبيئة تجريبية ببيانات صناعية، ولا يكفي لحساب يحمل طلبات حقيقية: أي سكربت يعمل في الصفحة يقرأه، ولا انتهاء صلاحية على مستوى المتصفح.

**قبل الإنتاج**: كوكي `HttpOnly` + `Secure` + `SameSite`، أو ربط الجلسة بحساب حقيقي عند أول طلب مدفوع.

### ٤. نقل المعاينة وإعادة المستودع Private

المستودع **عام**، وهذا سبب مجانية المعاينة على GitHub Pages — فPages على مستودع خاص يحتاج خطة مدفوعة.

**الترتيب يهمّ**: اربط مضيفاً يدعم المستودعات الخاصة مجاناً (Cloudflare Pages أو Netlify؛ أمر البناء `npm run build` والمخرج `dist`، والمتغيّرات نفسها الموجودة في `.github/workflows/preview.yml`) → تأكّد أن الرابط الجديد يعمل → ثم حوّل المستودع إلى خاص واحذف `gh-pages`. **لا تجعله خاصاً قبل أن يعمل البديل، وإلا تسقط المعاينة.**

### ٥. ربط الدفع والشحن والإشعارات الحقيقية

كلها اليوم محوّلات وهمية، وصندوق الصادر يسجّل ما كان سيُرسل ولا يرسل شيئاً. الاستبدال يمسّ مالاً حقيقياً ورسائل تصل عملاء حقيقيين، فهو قرار تجاري لا تقني — ولا يبدأ قبل حسم سياسة السعر النهائية.
