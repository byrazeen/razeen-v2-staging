## 6) ماذا كان سيحدث لو طبّقتُ حواجز العزل

| الحاجز المطلوب | الأثر الفعلي على `byrazeen.com` |
|---|---|
| **Environment Guard يوقف التطبيق عند اكتشاف Supabase الإنتاج** | 🔴 **الموقع يتوقف عن العمل بالكامل** — لأن هذا **هو** مشروع الإنتاج |
| **`noindex, nofollow`** | 🔴 **حذف المتجر من نتائج جوجل** |
| **شريط «RAZEEN V2 — STAGING»** | 🔴 يظهر لكل عميل حقيقي |
| **منع الدفع الحقيقي** | 🔴 **توقف المبيعات** |
| **منع WhatsApp** | 🔴 توقف تأكيدات الطلبات وOTP العملاء |
| **منع إنشاء الشحنات** | 🔴 توقف التجهيز |
| **منع تعديل مخزون Production** | 🔴 تجمّد المخزون |
| **بيانات تجريبية بدل الحقيقية** | 🔴 خطر على 1,277 طلباً |

**وحتى العمل على فرع منفصل لا يزيل الخطر**: التكليف نصّ على أن كل مرحلة تدخل عبر PR إلى `main` — و`main` هنا **هو الإنتاج**. أي دمج كان سيُسقط الموقع.

**التكليف نفسه حمل الصمّام الصحيح**: «إذا اكتشفت أن المشروع متصل بأي جزء من Production، **لا تبدأ البناء قبل عزله**». وهذا ما فعلته.
